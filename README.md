# Contact Management System

A full-stack Contact Management System built using **Node.js, Express.js, MongoDB, Mongoose, HTML, CSS, and JavaScript**.

The application allows users to create, view, update, search, and delete personal and professional contacts through a web interface and RESTful APIs.

---

## Features

- Add new contacts
- View all contacts
- View a single contact
- Update contact details
- Delete contacts
- Search contacts
- Phone number validation
- Email format validation
- Unique contact ID
- Unique email address
- Proper validation and error handling
- MongoDB database integration
- Responsive web interface

---

## Technologies Used

### Backend

- Nodemon

### Frontend

- CSS3
- JavaScript
